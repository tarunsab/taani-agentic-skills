# Beautiful HTML Templates

Use the bundled `AGENTS.md` as the detailed operating manual for this skill.

For every deck request:

1. Ask for the occasion and desired mood if they are not already clear.
2. Read `index.json` and shortlist three genuinely different templates using mood, tone, occasion, formality, density, and color scheme.
3. Read only the shortlisted templates' metadata and preview assets before choosing.
4. After the user chooses, adapt the selected template while preserving its fonts, palette, layout grid, decorative language, and runtime.
5. Replace placeholder copy, images, labels, stats, and dates with the user's real content.
6. Keep the result responsive, keyboard-accessible, and faithful to the selected visual system.

The bundled `templates/` directory contains the source templates. Read `index.json` first and load only the files needed for the current choice.
