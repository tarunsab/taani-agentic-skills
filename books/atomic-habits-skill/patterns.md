# Reusable patterns

## Identity-backed system

Start with the person the user wants to become, then choose a repeatable behavior that provides evidence for that identity. Use when goals feel abstract or motivation fluctuates, because the identity gives the daily action a reason to matter before the outcome arrives. Translate the identity into an observable vote, such as opening the book, sending the update, or preparing the healthy option. Avoid turning an identity into a rigid label; it should guide experimentation and recovery rather than make one lapse feel like a contradiction.

## Scorecard and awareness

List the current sequence of habits in a normal day, then mark each as helpful, harmful, or neutral relative to the user's current aim. Use before changing a behavior because an unnamed cue or automatic step cannot be redesigned precisely. Record observable actions and surrounding context rather than broad judgments about productivity or character. Awareness comes before redesign, and the purpose of the scorecard is to reveal one useful intervention point rather than create a permanent audit of every action.

## Implementation intention

Specify behavior, time, and location. Use when a good intention keeps getting postponed because “later” leaves the decision open to competing demands. Choose a cue that is stable, visible, and close to the first physical step. If the time or place is unreliable, use a dependable event or create more than one acceptable implementation intention rather than pretending the original cue is stable.

## Habit stacking

Attach a new behavior to a reliable current habit. Use when the user already has a stable routine that naturally leads to the desired response. The anchor must happen often enough for the new behavior to receive repeated cues, and the added action should be small enough not to overload the existing sequence. If the anchor is missed frequently, replace it with a more dependable event or use a time-and-place intention.

## Environment reset

Place tools for the desired action in the path of least resistance and remove competing cues from view. Use when the user is relying on self-control despite repeatedly encountering the same trigger. Change context when the old environment is saturated with unwanted associations or when the competing response is already automatic. Judge the reset by the next real decision it changes, and pair the new cue with a response that is clear enough to begin immediately.

## Temptation bundling

Pair a needed behavior with an immediately enjoyable one. Use when the behavior is useful but not appealing and the enjoyable activity is available at the same time. Make the reward contingent on beginning the target behavior, but keep the bundle honest and sustainable enough to repeat. If the enjoyable activity becomes the only thing the user pursues, reduce its size or choose a reward that supports rather than overwhelms the target.

## Friction shaping

Reduce steps for the desired behavior and add steps for the unwanted one. Use when the problem is initiation rather than knowledge, especially when the user already knows what to do but defaults to the easier option. Favor one-time setup changes that improve many future repetitions, such as preparing materials or changing a default. Confirm that the easier behavior is genuinely valuable, and avoid removing friction that protects safety, quality, or deliberate choice.

## Two-minute gateway

Define a version that starts in roughly two minutes, then allow the session to expand naturally. Use to overcome resistance to starting when the full routine feels too large at the decisive moment. The gateway is the habit; extra effort is optional until repetition is stable enough to support gradual expansion. Keep the gateway connected to the larger routine so it opens a meaningful path, but do not hide a large project inside a supposedly tiny action.

## Immediate reinforcement

Make completion feel successful now with a checkmark, brief reward, or visible evidence. Use for behaviors whose main benefits are delayed, because the immediate signal teaches the brain that the response was worth repeating. Choose reinforcement that is available immediately and does not create more friction than the habit. Do not let the reward undermine the larger aim or become so elaborate that the user is really practicing the reward system instead of the behavior.

## Never-miss-twice recovery

Treat a miss as a signal to resume at the next opportunity. Use to prevent an exception becoming a new identity or routine, while keeping the recovery action small enough to complete without drama. The point is not to preserve a perfect streak; it is to prevent one disruption from becoming the new default. Diagnose the system if misses recur, because repeated lapses usually reveal a cue, minimum, environment, or reward that needs redesign.

## Accountability contract

Make the cost of violating a commitment immediate and socially visible. Use when private intentions are too easy to ignore and another person can provide reliable, respectful feedback. Define the behavior, evidence, check-in, and consequence before the lapse occurs so that the arrangement does not depend on an argument in the moment. Choose an accountability partner and consequence that are clear, proportionate, and consensual, with a recovery path that supports honesty rather than shame.

## Deliberate-practice loop

Work at the edge of current ability, receive feedback, and repeat with focused correction. Use when the user wants mastery rather than mere consistency, because automatic repetition can preserve errors as efficiently as it preserves good technique. Define one quality criterion and one correction for the practice block so that effort produces information. Adjust difficulty to avoid both discouragement and boredom while keeping the basic cue and minimum version stable.

## Reflection and identity update

Review the system periodically, keep what works, and revise beliefs that have become too narrow. Use after a plateau or major change in circumstances, or when a habit remains consistent but its quality or purpose is unclear. Separate the automatic parts that should remain easy from the parts that need deliberate attention and feedback. Habits should serve growth, not imprison it, so update the identity and system when the person has genuinely outgrown the old version.
