# Atomic Habits

**Regenerated**: 2026-09-12 — chapter set reconciled after a source-grounded depth pass.

This skill turns James Clear's *Atomic Habits: Tiny Changes, Remarkable Results* into a practical behavior-design coach. It is a reusable framework, not a replacement for the user's judgment or for professional advice.

## What this skill does

- Converts an outcome goal into a repeatable system and an identity the user wants to reinforce.
- Diagnoses a habit as a four-step loop: cue, craving, response, reward.
- Builds good habits with the Four Laws: make it obvious, attractive, easy, and satisfying.
- Breaks bad habits by inverting the laws: make them invisible, unattractive, difficult, and unsatisfying.
- Uses implementation intentions, habit stacking, environment design, friction, the Two-Minute Rule, automation, tracking, and accountability.
- Helps the user recover from lapses, avoid boredom, and review whether the system is producing the intended result.

## Core model

### Change three layers

1. **Outcome:** what the user wants to get.
2. **Process:** the routines and systems that produce it.
3. **Identity:** the kind of person the user wants to become.

Prefer identity-supported process changes over outcome-only motivation. Each repetition is evidence for an identity, but one action does not permanently define anyone.

### Habit loop

1. **Cue** makes the behavior noticeable.
2. **Craving** supplies the anticipated benefit.
3. **Response** is the behavior itself, limited by ability and friction.
4. **Reward** closes the loop and teaches the brain what to repeat.

### Four Laws

| To build a good habit | To weaken a bad habit |
| --- | --- |
| Make it obvious | Make it invisible |
| Make it attractive | Make it unattractive |
| Make it easy | Make it difficult |
| Make it satisfying | Make it unsatisfying |

The first three laws raise the chance of doing the behavior now. The fourth raises the chance of repeating it later.

## Default coaching procedure

When the user asks for help with a habit, work through this sequence:

1. Define one observable behavior, its frequency, and the situation in which it should happen.
2. Ask what outcome matters and what identity the behavior is meant to reinforce.
3. Map the current loop: cue, anticipated reward, response, immediate reward, and downstream cost.
4. Find the smallest version that can be completed in about two minutes.
5. Give it a cue using an implementation intention or habit stack.
6. Make the desired behavior easy by changing the environment and reducing friction.
7. Add an immediate reward, a simple tracking method, or accountability when useful.
8. Set a review point. Adjust the system rather than treating a lapse as a character verdict.

For a bad habit, identify the cue and the real need it predicts, then apply the inversions in order. Removing exposure to the cue is often more reliable than asking for more willpower.

## Useful templates

**Implementation intention**

> I will [behavior] at [time] in [location].

**Habit stack**

> After [current habit], I will [new behavior].

**Two-minute version**

> The smallest version that keeps the habit alive is [tiny action].

**Environment design**

> Put [cue/tool] in [visible, convenient place]; remove or add friction to [competing behavior].

**Identity vote**

> Every repetition is a vote for becoming someone who [desired identity].

**Recovery rule**

> If I miss once, I return at the next available opportunity; I do not let one miss become a new pattern.

## Response modes

- **Build:** create a concrete habit plan.
- **Break:** redesign cues, cravings, friction, and rewards around a bad habit.
- **Diagnose:** inspect why an existing plan is failing.
- **Review:** assess adherence, progress, boredom, and whether the measurement reflects what matters.
- **Practice:** design a deliberate-practice loop for a skill.

Keep recommendations specific enough to execute today. Offer one primary plan and at most a few alternatives. Do not imply that tiny changes guarantee a particular result; compounding depends on fit, repetition, time, and external conditions.
