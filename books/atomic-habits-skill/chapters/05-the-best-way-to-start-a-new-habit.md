# Chapter 5 — The Best Way to Start a New Habit

## Core lesson

Good intentions become more reliable when tied to a specific time and place. A cue that is vague, distant, or dependent on a fluctuating mood leaves too many decisions to the moment of action. Existing routines can act as stable anchors for new behaviors because they already occur in a recognizable sequence. The best cue is not necessarily the earliest possible time; it is the one that is dependable and close enough to the behavior that the connection can be repeated. Specificity helps the user notice when the opportunity has arrived and prevents “later” from becoming the default schedule.

## Tools

**Implementation intention:** “I will [behavior] at [time] in [location].”

**Habit stack:** “After [current habit], I will [new behavior].”

The implementation intention fixes a behavior to a time-and-place cue, while a habit stack fixes it to an existing action. Both reduce the need to renegotiate the plan each day. Use an implementation intention when a time or location is stable; use a stack when a current routine is more reliable than the clock. The behavior in the blank should describe the first observable action, not a broad aspiration. If the cue changes often, make the plan conditional on a stable event or prepare more than one acceptable cue.

## Use it

Choose a cue that is stable, visible, and close to the desired action. Make the behavior observable: “open the notebook and write one sentence” is stronger than “work on my project.” Keep the first step close enough to the cue that the chain does not depend on memory. If the anchor habit is unreliable, replace it with a more dependable event or use a time-and-place intention instead. After several repetitions, inspect whether the cue still occurs and whether the chosen behavior is genuinely small enough to begin without negotiation.

## Example structure

After I make my morning coffee, I will open my language app at the kitchen table and complete one exercise.

This example works because the anchor is a familiar event, the location is concrete, and the response is observable. “Improve my language skills after coffee” would leave the action and stopping point undefined. The exercise can later grow, but the first commitment is to begin the sequence reliably. If mornings become unpredictable, the same habit can be attached to another stable routine rather than treated as a personal failure.

## Pitfall

Choosing a time or anchor that sounds ideal but rarely occurs creates a plan that fails before the behavior is even considered. Adding more precision cannot compensate for an unavailable cue. Another problem is stacking onto a routine that is itself variable, such as “after I feel ready,” because the supposed anchor provides no reliable signal. Test the cue for a week and replace it if it is missed for reasons unrelated to the desired behavior. Precision helps only when the opportunity actually exists in the user's life.
