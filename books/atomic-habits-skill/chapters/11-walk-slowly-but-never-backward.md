# Chapter 11 — Walk Slowly, but Never Backward

## Core lesson

Repetition, not planning, turns a behavior into a habit. The chapter's photography-class example makes the distinction concrete: students assigned many photographs learned through experimentation and mistakes, while students asked for one perfect image spent more time theorizing. Planning can clarify the route, but it does not provide the learning that comes from actually performing the behavior. The number of repetitions matters more than the calendar time since starting because each repetition strengthens the cue–response connection and gradually increases automaticity. Motion that feels productive—researching, organizing, or refining a plan—is not the same as taking action that changes the situation. Begin with a version that can be repeated often enough to produce feedback, then improve the routine from observed friction rather than imagined obstacles.

## Use it

Reduce the distance between intention and the first physical step. Run small experiments, repeat them, and let feedback improve the routine instead of trying to perfect the system in advance. Count useful repetitions rather than treating a number of calendar days as evidence by itself; the book's walking example shows automaticity rising as the behavior is repeated. Separate preparation from the behavior itself so that a well-organized plan does not become a substitute for practice. Standardize a workable version before optimizing it, because optimization requires something stable enough to compare. If the behavior is not repeating, shrink or simplify the action before adding more analysis.

## Diagnostic questions

- What action counts as starting?
- Which steps are preparation rather than the behavior?
- How many repetitions can the user realistically get this week?
- What feedback would show whether the routine is improving?

These questions locate the gap between intending to act and actually acting. A useful answer names a physical or observable step rather than a mental state such as “feel focused.” The repetition estimate should fit the user's real schedule, because an ideal frequency that rarely occurs cannot teach the habit reliably. Feedback should examine both adherence and quality so that repeated errors are not mistaken for progress. Use the answers to redesign one bottleneck, then gather new evidence through another round of practice.

## Pitfall

Spending another week refining a plan that has not yet been practiced confuses preparation with learning. A detailed plan can still fail if the first step is too large, the cue is unreliable, or the environment adds hidden friction. Starting with a smaller version is not lowering the ambition of the outcome; it is creating the repetitions needed to discover what the system requires. Once practice reveals the real bottleneck, improve that bottleneck instead of adding general advice. Start with a version that is good enough to repeat and let evidence earn the next optimization.
