# Chapter 10: The Library Stakeout

## Core Idea

The telephone trace reaches a Pacific Bell number, and Stoll wonders whether the intruder is using public library terminals or another shared facility. A physical stakeout produces no answer, reminding him that a plausible telephone location is not the same thing as a person at that location. The failed stakeout is not wasted: it narrows the interpretation of the phone evidence and pushes the investigation back toward the network path. In a case built from remote sessions, physical intuition must be tested rather than allowed to replace measurement.

## Frameworks Introduced

- Hypothesis testing
- Physical corroboration
- Negative evidence

## Key Concepts

- Pacific Bell number
- Public terminal hypothesis
- Stakeout
- Remote session

## Mental Models

- The empty stakeout
- A location is not an identity

## Anti-patterns

- Treat the first physical lead as conclusive
- Discard a failed hypothesis without recording what it ruled out

## Worked Example

Stoll follows the number because a person using a public terminal would fit the available facts, but the observation does not reveal a culprit. The absence of a useful sighting weakens that story without proving the opposite. This is a small example of the book's recurring practice: let failed searches refine the model instead of forcing the evidence to fit the narrative.

## Key Takeaways

- Record what a failed search rules out.
- Corroborate network evidence with physical evidence when possible.
- Keep multiple hypotheses alive until a discriminating observation arrives.
