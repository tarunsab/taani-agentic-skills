# Chapter 51: The Last Session

## Core Idea

In June, the hacker spends a long session reading the fake SDI files and searching for the supposed network link, while Stoll adds breadcrumbs that make the decoy more informative. A separate Petvax/NASA SPAN event may be a different intruder, so Stoll refuses to merge cases merely because the systems overlap. The FBI says an arrest is imminent, and on June 21 the known hacker returns for only five minutes, leaving the investigation without another long trace opportunity. The chapter turns the final session into a lesson in closure: a case can end because the evidence and authorities have converged, not because every uncertainty has vanished.

## Frameworks Introduced

- Case separation
- Breadcrumb decoy
- Evidence-based closure

## Key Concepts

- Petvax
- NASA SPAN
- SDI files
- Five-minute session
- Arrest window

## Mental Models

- The last observable state
- Related incident versus same actor

## Anti-patterns

- Merge incidents based only on shared infrastructure
- Keep monitoring indefinitely after the actionable question is answered

## Worked Example

Stoll compares the NASA event with the established behavioral and target profile and decides it may be separate. The known hacker's final short connection does not provide a dramatic climax, but the authorities now have enough route, timing, and physical evidence to proceed. The source preserves the distinction between “the hunt is ending” and “the network is now safe.”

## Key Takeaways

- Test whether two incidents share behavior, timing, and purpose before merging them.
- Use decoys to make the final sessions informative without increasing real exposure.
- Define what evidence is sufficient for handoff or closure.
