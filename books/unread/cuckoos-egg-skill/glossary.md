# Glossary

**AFOSI** — Air Force Office of Special Investigations, one of the military contacts in the case (Ch 8).
**Arpanet** — The early wide-area network through which later incidents and connections spread (Epilogue).
**Bailiwick** — An agency's claimed area of responsibility; the book shows how it can become a gap between agencies (Ch 12).
**BBN Butterfly** — A networked VAX system reached through weak access controls (Ch 44).
**Bevatron** — LBL accelerator whose computers also support cancer treatment, making system compromise safety-critical (Ch 38).
**BKA** — Germany's Federal Criminal Police Office, the counterpart involved in international legal coordination (Ch 35).
**Bundespost** — West Germany's postal and telecommunications authority, including the Datex network staff who trace the route (Ch 30).
**Cuckoo's egg** — A hostile program placed in a legitimate system so the system hatches the intruder's privilege (Ch 4).
**Datex** — German packet-network service used in the international route (Ch 30).
**Dictionary attack** — Testing likely words against a stolen one-way password value; weak human secrets make this economical (Ch 47).
**DNIC** — A network identifier whose digits encode national and service information in the book's traces (Ch 34).
**Elxsi** — A computer reached through an open privileged network account and used as a monitored stepping-stone (Ch 20).
**Evidence window** — The bounded period in which continued observation is worth the risk of leaving a route available (Ch 5).
**Field-service account** — A maintenance account that can become a master key when its default credential is left unchanged (Ch 37).
**Gnu-Emacs flaw** — The move-mail weakness that lets a normal user replace a privileged program and gain super-user access (Ch 4).
**Hacker** — In the book's usage, a person who enters systems without authorization; the narrative distinguishes ability from motive (Ch 2).
**Hunter** — The first unexplained account name and an early behavioral clue (Ch 1).
**Kermit** — A file-transfer program used by the intruder to move software and data across systems (Ch 9).
**Logbook** — Stoll's dated record of observations, calls, decisions, and uncertainty; it becomes evidence and a publication base (Ch 35).
**Milnet** — The military network repeatedly probed from the compromised route (Ch 8).
**Mitre** — A defense contractor whose open outgoing modem paths become a plausible stepping-stone (Ch 22).
**NCSC** — National Computer Security Center, focused on standards and security rather than taking over the live hunt (Ch 21).
**Network footprint** — Observable traces left by a remote session: timing, route, commands, and account changes (Ch 3).
**Operation Showerhead** — The bounded decoy experiment using synthetic SDINET documents to extend a session for tracing (Ch 34).
**Optimis** — An Army database searched for sensitive strategic topics (Ch 36).
**Password file** — A protected store of one-way password values that becomes dangerous when exposed to offline guessing (Ch 47).
**Privilege escalation** — Movement from ordinary user authority to system-manager authority by altering a program or exploiting a boundary (Ch 4).
**Root / super-user** — The highest Unix authority, able to bypass file protections and alter the system (Ch 2).
**SDINET** — The fictitious Strategic Defense Initiative Network used as a low-risk canary and time-extension bait (Ch 40).
**Sventek** — A real former LBL user whose stolen credentials mask the intruder's identity (Ch 1).
**Tymnet** — The commercial packet network whose operators help trace connections across national systems (Ch 6).
**Trojan horse** — A program that appears legitimate while capturing credentials or performing a hidden action (Ch 9).
**UUCP** — A Unix networking facility whose open privileged account provides a route into another system (Ch 20).
**VMS** — Digital Equipment Corporation's operating system, whose system privileges and later universal flaw feature in the case (Ch 37).
**Virtual circuit** — A logical network path whose identifiers and hops change as traffic crosses carriers (Ch 29).
**Watchdog** — A separate monitoring system that observes other hosts and alerts the investigator (Ch 6).
