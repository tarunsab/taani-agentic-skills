# Cheatsheet

## Fast decisions

| Question | Use this rule | Inspect |
|---|---|---|
| How can a new technology reach scale? | Secure an urgent launch customer, then use volume to learn. | Customer mission, funding, feedback, yield |
| Is copying enough? | No: distinguish the design from the production recipe. | Equipment, materials, maintenance, operators, tacit know-how |
| What makes an industry viable? | Combine talent, capital, customers, suppliers, process learning, and policy. | Complements, not just a flagship firm |
| Should a firm own a fab? | Choose by chip category and economics, not prestige. | Logic vs. memory vs. analog; fixed cost; utilization |
| Where is strategic leverage? | Find the least substitutable chokepoint. | EDA, tools, materials, fab, packaging, assembly |
| How should a weaker actor compete? | Use an offset in a different dimension. | Precision, sensing, networking, software, autonomy |
| When should an incumbent change? | Ask what a replacement CEO would stop protecting. | New architecture, ignored customer, shrinking moat |
| What caused a shortage? | Separate demand, inventory, allocation, logistics, and capacity. | Time sequence and cancellations |
| How should resilience be built? | Protect the network, not only a domestic factory. | Allied ownership and replacement time |

## Core distinctions

| Do not conflate | Keep separate |
|---|---|
| Chip design | Fabrication, packaging, and assembly |
| A working prototype | High-yield mass production |
| A stolen blueprint | Tacit process capability |
| Global trade | Distributed control |
| Efficiency | Resilience |
| A customer country | A producer's home country |
| Tariffs | Targeted controls on actual chokepoints |
| More transistors | Lower system cost or better usable performance |

## Chokepoint worksheet

1. Draw the chain from architecture and EDA through equipment, materials, wafer fabrication, packaging, assembly, and end system.
2. Mark each node's owners, substitutes, lead time, and allied exposure.
3. Rank nodes by irreplaceability, concentration, and enforceability.
4. Model second-order effects: retaliation, substitution, domestic damage, and ecosystem fragmentation.

## Ecosystem test

An industry-building plan is incomplete if it names only a fab. Ask whether it also has skilled people, patient capital, demanding customers, reliable suppliers, equipment access, design tools, process-learning time, and a path to profitable volume.

## Strategic risk signals

- One geography supplies an irreplaceable process.
- One customer funds the next generation but is also a strategic competitor.
- A firm optimizes the current product while an alternative architecture improves.
- A policy treats a distributed network as if it were a single national factory.
- A technical milestone is celebrated without yield, cost, or integration evidence.
