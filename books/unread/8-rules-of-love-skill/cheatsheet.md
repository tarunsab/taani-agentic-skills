# Cheatsheet — 8 Rules of Love

## Choose the classroom

| If the recurring problem is… | Start with… |
|---|---|
| Fear of being alone, unclear identity, dependency | Rule 1: solitude |
| Repeated attraction, triggers, or “bad luck” | Rule 2: karma review |
| Ambiguous feelings or declarations | Rule 3: define phases and agreements |
| Control, criticism, or stalled growth | Rule 4: mutual guru/student |
| Envy, merging, or lost ambition | Rule 5: protect both dharmas |
| Repeating arguments | Rule 6: shared goal + PEACE |
| Danger, structural rupture, or breakup | Rule 7: safety + elevate/separate |
| Love narrowed to a few people | Rule 8: radius expansion |

## Fast decision rules

- If loneliness is choosing for you, pause the relationship decision and practice chosen solitude.
- If the same result repeats, ask which impression and choice are being repeated before blaming fate.
- If “I love you” has different meanings, replace the phrase with questions about commitment, pace, values, goals, and behavior.
- If helping feels like control, ask: “What matters? What do you need? Is there anything I can do?”
- If an argument has a winner and loser, reframe until the problem—not the partner—is the loser.
- If a behavior is unsafe or coercive, stop using relationship techniques and seek specialized help.
- If a purpose arrangement changes time, money, childcare, or household work, write the agreement and a review date.
- If a breakup is chosen, be clear and compassionate; closure and value are responsibilities you give yourself.
- If a difficult person harms proximity, keep a radius of respect: less contact, public settings, or other sources of support.

## Love-phase check

| Phase | Ask |
|---|---|
| Attraction | Do I want to learn who this person actually is? |
| Dreams | Are fantasy and checklist hiding reality? |
| Struggle/growth | Will we resolve, accept, or honestly leave this difference? |
| Trust | Do repeated actions show physical, mental, and emotional safety? |

## PEACE prompt

**P**lace/time → **E**xpression → **A**nger management → **C**ommitment → **E**volution. End with a real apology: accept the impact, articulate the change, and act differently.

## Purpose prompt

Learn → Experiment → Thrive → Struggle → Win. When two purposes collide, choose after-hours protection, one explicit priority, alternating turns, or both at once—then name the sacrifice and revisit it.

## Expansion prompt

Ask in each room: “How can I bring love here?” Give one specific act within your capacity, without demanding praise or reciprocity.
