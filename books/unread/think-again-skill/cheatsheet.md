# Cheatsheet

## Choose the mode

| Situation | Default move | Watch for |
|---|---|---|
| Forming your own view | Scientist: hypothesis, evidence, update | Preacher certainty; prosecutor rebuttals; political approval-seeking |
| Confidence feels high | Test explanation, seek critics | Mount Stupid; confirmation/desirability bias |
| Confidence feels low | Trust capacity to learn; question method | Paralysis or chronic shame |
| Another person resists | Listen, ask, reflect, affirm autonomy | Righting reflex; fact dumping |
| Team disagrees | Task conflict + shared goal | Personal attacks; HIPPO silence |
| Public issue is polarized | Complexify; add caveats and contingencies | Two-camp framing; false balance |
| Plan is failing | Check process, run a bounded pivot | Sunk-cost escalation; grit as stubbornness |

## Rethinking loop

1. Name the assumption and what you do not know.
2. Write the evidence or event that would change your mind.
3. Search actively for disconfirming information and a thoughtful critic.
4. Run a small, reversible test where possible.
5. Update, record the reason, and let the new answer stay provisional.

## Confidence calibration

- Confidence in **capacity** + doubt in **current method** = confident humility.
- If you cannot explain how it works, reduce confidence and investigate.
- If doubt prompts effort, smarter strategy, and listening, use it; if it becomes unworthiness, seek support.
- Prefer a few extra updates to one dramatic reversal at the end.

## Debate and listening sequence

| Step | Ask/do |
|---|---|
| 1 | “What do we agree is true or important?” |
| 2 | Steel-man the strongest opposing case. |
| 3 | Ask “How would that work?” and “What evidence would change your mind?” |
| 4 | Give a few cohesive reasons, not every reason you have. |
| 5 | Ask permission before supplying information; reflect and affirm autonomy. |
| 6 | If heated, discuss the conversation; if nothing could change, stop. |

## Build learning systems

- Psychological safety is permission to speak, not low standards.
- Pair safety with process accountability to create a learning zone.
- Score both outcome and process: good outcome + shallow process = luck; bad outcome + deep process = smart experiment.
- Replace “best practice” with “better practice”; investigate anomalies and near misses.
- Use challenge networks, six-page decision memos, independent review, and “disagree and commit” for bounded bets.

## Keep the future open

At a twice-yearly checkup ask: When did I form this plan? How have I changed? What has plateaued? Which possible self could I test through an interview, shadowing, sample project, or changed daily action? Compare the cost of leaving with the cost of staying for the next decade, not only the past two years. Seek meaning through learning, connection, and contribution; change actions before assuming a new setting will fix the self.
