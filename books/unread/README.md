# Unread book skills

This directory contains book-derived skills for books that have not yet been
read. Each child directory is one book skill. A child with `SKILL.md` has a
usable skill entry point; directories without it are preserved interrupted
drafts awaiting completion.

The matching iCloud skill folders are stored beside their source books with an
`unread-` prefix. These unread book copies are intentionally kept out of the
Obsidian vault until the books have been read.
