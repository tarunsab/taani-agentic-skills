# Cheatsheet

## Fast Decision Aid

| Question | Book-grounded rule |
|---|---|
| What should we build first? | Find the repeated user behavior and make its simplest useful version fast, legible, and low-risk. |
| Should we add a constraint? | Yes when it improves coherence or lowers participation cost; remove it when evidence shows it blocks a common job. |
| How do we seed a community? | Invite credible model users, curate examples, and create rituals that teach the norm. |
| What is the real moat? | Community trust, habit, authorship, and network effects—not only the feature implementation. |
| Can we trust the metric? | Ask who can game it, what behavior it rewards, and whether it tracks the outcome you actually value. |
| When should we monetize? | After the product has earned tolerance; review early commercial work manually and keep disclosure visible. |
| How should we respond to a rival? | Identify the underlying job, then build, acquire, or contain with awareness of market-power costs. |
| What does an acquisition promise require? | Explicit control over staffing, roadmap, distribution, integrity, data, and succession. |
| How should we handle safety? | Give integrity named ownership and measure prevention, not merely visible engagement or removals. |

## Warning Signs

- Top-line accounts rise while posts per user fall: investigate posting pressure and contribution cost.
- Recommendations make “honest” accounts suddenly profitable: audit whether curation is creating a hidden market.
- A metric controls pay or status: expect coordination, bots, purchased attention, or content optimized for the proxy.
- A policy has a tool but no enforcement: the tool may transfer liability without changing behavior.
- A subsidiary is blamed for outcomes but cannot hire or prioritize: there is an accountability gap.
- A well-being feature hides a number while analytics become richer: the incentive may have moved, not disappeared.

## The Book’s Core Loop

`product choice → measurable reaction → user optimization → cultural norm → commercial and social consequence`

Interrupt the loop by changing the reward, the ranking, the default, or the ownership—not only by asking users to behave differently.
